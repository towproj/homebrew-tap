# towproj/homebrew-tap

The Homebrew tap for [tow](https://github.com/towproj/tow), on macOS:

```bash
brew install towproj/tap/tow
```

Each tow release writes `Casks/tow.rb` here; nothing in it is edited by hand. The Test workflow then installs tow from this tap on Apple Silicon and Intel macOS runners and checks the version. Other ways to install tow: [the install docs](https://towproj.github.io/tow/docs/install/).
